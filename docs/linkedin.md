## Português

Qual jogo de Pokémon combina com você? Construí um site inteiro para responder a essa pergunta.

O PokéAtlas é um guia visual dos jogos de Pokémon com cara de Pokédex: corpo vermelho, lente azul, tela e teclas. Cada jogo vira um hexágono de seis atributos (história, exploração, dificuldade, liberdade, competitivo e nostalgia), e uma bússola de oito perguntas desenha o seu perfil ao vivo e mostra os jogos que mais se parecem com ele.

O que tem lá dentro:

🔴 30 jogos, 10 regiões com cartas redesenhadas e as 1.025 espécies, cada uma com a sua página
🔴 Montador de time no formato da tela de equipe dos jogos, com fraquezas e resistências em selos de tipo
🔴 Linha do tempo, comparador de jogos, desafios com roleta e um diário para acompanhar um Nuzlocke
🔴 Uma segunda edição sobre o mod Cobblemon, com 888 Pokémon, 490 itens e 65 estruturas que giram em 3D
🔴 Música de fundo e sons de tecla gerados na hora pelo navegador, e o grito de cada Pokémon

Por baixo do capô, foi um exercício de fazer muito com pouco:

▪️ Zero dependências em produção: HTML, CSS e JavaScript puro, sem framework
▪️ Um gerador de site estático próprio, que valida os dados e escreve 1.986 páginas em cerca de um segundo
▪️ 3D em WebGL sem biblioteca, com um desenhista de software para quando o navegador não ajuda
▪️ A trilha sonora é uma partitura em texto tocada com osciladores, sem arquivo de música
▪️ Testes de unidade e roteiros de navegador para cada ferramenta

É um projeto de fã, sem fins lucrativos e sem vínculo com a Nintendo ou com a The Pokémon Company.

🔗 Site: https://pokeatlas-eight.vercel.app/
💻 Código: https://github.com/Avendanho/Projeto-Vitrine-Jogos

## English

Which Pokémon game is the one for you? I built a whole website to answer that.

PokéAtlas is a visual guide to the Pokémon games that looks like a Pokédex: red body, blue lens, a screen and keys. Every game becomes a hexagon of six attributes (story, exploration, difficulty, freedom, competitive and nostalgia), and an eight-question compass draws your own profile live and shows the games closest to it.

What is inside:

🔴 30 games, 10 regions with redrawn maps and all 1,025 species, each with its own page
🔴 A team builder laid out like the games' party screen, with weaknesses and resistances as type badges
🔴 A timeline, a game comparison, challenges with a roulette and a journal to track a Nuzlocke run
🔴 A second edition about the Cobblemon mod, with 888 Pokémon, 490 items and 65 structures you can rotate in 3D
🔴 Background music and key sounds generated live by the browser, plus every Pokémon's cry

Under the hood, it was an exercise in doing a lot with very little:

▪️ Zero production dependencies: plain HTML, CSS and JavaScript, no framework
▪️ A custom static site generator that validates the data and writes 1,986 pages in about one second
▪️ 3D in WebGL without a library, with a software renderer for when the browser does not cooperate
▪️ The soundtrack is a score written as text and played with oscillators, with no music file
▪️ Unit tests and browser scripts for every tool

The site is in Brazilian Portuguese. It is a non-profit fan project, not affiliated with Nintendo or The Pokémon Company.

🔗 Site: https://pokeatlas-eight.vercel.app/
💻 Code: https://github.com/Avendanho/Projeto-Vitrine-Jogos
